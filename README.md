# 学习汉语 · xuexihanyu

Одностраничное веб-приложение для изучения китайских иероглифов (или любых слов) с помощью флеш-карточек. Дизайн — тёплая «императорская» палитра (бордовый + золото), шрифты Noto Serif SC / Noto Sans SC / Ma Shan Zheng.

Технологии: HTML + CSS + JS без сборки. Работает в двух режимах:

- **Без аккаунта** — данные хранятся в `localStorage` браузера, ничего настраивать не нужно.
- **С аккаунтом** — уроки, слова и прогресс хранятся в облаке ([Supabase](https://supabase.com) Postgres + Auth), доступны с любого устройства. Требует один раз пройти [SETUP.md](SETUP.md) и вписать ключи проекта в [`config.js`](config.js); пока это не сделано, приложение автоматически работает без аккаунта.

## Запуск

Просто открой [index.html](index.html) в браузере — сервер не требуется.

Чтобы включить аккаунты и облачное хранение — см. [SETUP.md](SETUP.md).

## Функционал

- **Аккаунты**: регистрация и вход по email/паролю, вход через Google, восстановление пароля — на базе Supabase Auth. Гостевой режим как fallback («Продолжить без аккаунта»), с предложением перенести локальные уроки в аккаунт при первом входе
- **Онбординг** для новых пользователей: создать первый урок или посмотреть примеры уроков
- Адаптивная раскладка: боковая панель навигации на десктопе (≥900px), нижняя панель с плавающей кнопкой «+» на мобильных
- Тёмная/светлая тема (переключатель на главном экране и в настройках)
- Создание, редактирование и удаление уроков
- Добавление слов по одному или массовой вставкой списка (через запятую, точку с запятой, табуляцию или дефис — `иероглиф, пиньинь, перевод`); пиньинь и перевод можно не указывать — сгенерируются автоматически
- Автогенерация пиньиня по иероглифу через [pinyin-pro](https://pinyin-pro.cn/) (CDN, без сборки), кнопка «Пиньинь автоматом» для массового заполнения
- Автоперевод иероглифа на русский (бесплатный неофициальный эндпоинт Google Translate) при пустом поле перевода — так же по blur, в массовой вставке и кнопкой «Перевод автоматом». Эндпоинт неофициальный, поэтому изредка может не отвечать (CORS/ограничения) — поле в этом случае просто остаётся пустым для ручного ввода
- Два режима тренировки: классические флеш-карточки (3D-переворот, цветные тона пиньиня) и «Угадай перевод» (выбор из 4 вариантов)
- Интервальное повторение (упрощённый алгоритм SM-2): кнопки «Знаю» / «Повторить» на каждой карточке, автоматический подсчёт в режиме «Угадай перевод»
- Раздел «Повторить сегодня» на главном экране — собирает слова из всех уроков, у которых подошёл срок повторения, с дневной целью и прогресс-баром
- Озвучка иероглифов при открытии карточки (Web Speech API, опционально)
- Статистика: серия дней подряд (с лучшим результатом), число выученных слов, точность в режиме «Угадай», график карточек по дням за 2 недели, очередь повторений по срокам
- Настройки: аккаунт (вход/выход), тема, автопиньинь, интервальное повторение, цвета тонов, озвучка, дневная цель
- Прогресс-бар, перемешивание карточек, повтор урока
- Понятные сообщения об ошибках (неверный пароль, занятый email, отсутствие интернета) и баннер о потере соединения в режиме аккаунта
