# 学习汉语 · xuexihanyu

Одностраничное веб-приложение для изучения китайских иероглифов (или любых слов) с помощью флеш-карточек.

Технологии: чистый HTML + CSS + JS, без сборки и без бэкенда. Все данные (уроки и слова) хранятся в `localStorage` браузера.

## Запуск

Просто открой [index.html](index.html) в браузере — сервер не требуется.

## Функционал

- Создание, редактирование и удаление уроков
- Добавление слов по одному или массовой вставкой списка в формате `иероглиф - пиньинь - перевод` (пиньинь можно не указывать — сгенерируется автоматически)
- Автогенерация пиньиня по иероглифу через [pinyin-pro](https://pinyin-pro.cn/) (CDN, без сборки)
- Два режима тренировки: классические флеш-карточки (3D-переворот) и «Угадай перевод» (выбор из 4 вариантов)
- Интервальное повторение (упрощённый алгоритм SM-2): пометка «Знаю» / «Повторить» на каждой карточке, автоматический подсчёт для режима «Угадай перевод»
- Раздел «Повторить сегодня» на главном экране — собирает слова из всех уроков, у которых подошёл срок повторения
- Статистика: график карточек по дням за последние 30 дней, текущий streak (дней подряд) и число выученных слов
- Прогресс-бар, перемешивание карточек, повтор урока
- Адаптивный дизайн для мобильных устройств
